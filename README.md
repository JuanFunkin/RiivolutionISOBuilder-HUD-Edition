# RiivolutionISOBuilder-HUD-Edition
Riivolution ISO Builder with a simple GUI to patch Nintendo Wii ISO/WBFS files using Riivolution XML mods. Fork of Asu-chan's original console tool, same patching engine, now with a proper window instead of the command line.

I decided to create this because some people don't fully understand command consoles (myself included), so I put everything into an easy-to-use, faster HUD.
